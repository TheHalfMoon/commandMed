## 2. Canonical schema finding

The current metric validator requires one non-empty string field:

```text

```

It does not encode separate evidence roles for selection versus final/private-Gold audit.

```text

CURRENT_METRIC_SCHEMA_DISTINGUISHES_SELECTION_AND_RELEASE_AUDIT_EVIDENCE=NO
```

Therefore the conflict is not safely repaired by merely changing prose interpretation of the current field.
