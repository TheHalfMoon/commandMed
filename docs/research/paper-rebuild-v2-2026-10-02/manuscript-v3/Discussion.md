# 7. Discussion

The proposed decision-contract view reframes reliability away from isolated answer correctness. For a machine-consumable interface, the model should respect semantic symmetries of the task while remaining responsive to changes that alter the evidence or available actions. This framing can produce several scientifically useful outcomes even if CRDI does not win.

If ordinary LM logits already satisfy the contract after a simple debiasing/calibration procedure, a dedicated decision architecture may be unnecessary. If typed heads improve latency but not contract behavior, the result narrows their value proposition. If contract regularization improves presentation robustness but damages evidence responsiveness, the negative result demonstrates that invariance objectives can be over-applied. If an effect survives matched supervision and independent-family replication, it supports a stronger architectural conclusion.

The medical setting raises the bar because confidence shifts can affect escalation, retrieval and downstream automation. However, benchmark decision tasks remain proxies. The study does not establish patient benefit, clinical safety, or regulatory fitness. Those claims require separate prospective validation.

The broader methodological question is whether contract-level evaluation generalizes beyond medicine. We will not infer this from a medical-only experiment. A general claim would require additional domains or formal task families and will be treated as future work unless independently tested.
