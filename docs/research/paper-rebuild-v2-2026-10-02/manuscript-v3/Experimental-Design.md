# 5. Experimental Design

## 5.1 Study phases

**Phase A — mechanical contract fixtures.** Verify mappings, probability conservation, transformation generators and metric code without a medical model claim.

**Phase B — small-model development.** Compare interfaces and objectives on legally admitted development data using the smallest viable open-weight backbones. Select architecture, hyperparameters and transformation mix.

**Phase C — frozen confirmatory study.** Quarantine the final test set and execute the preregistered primary contrast once per declared seed/model cell.

**Phase D — independent-family replication.** Repeat the decisive result on a second architecture family under the same directional estimand.

No flagship 27B experiment is necessary to establish the methodological result. Scaling occurs only if it answers an unresolved scientific question and genuinely free compute is available.

## 5.4 Metrics

Primary contract endpoint: CED. Co-primary decision endpoint: NLL. Additional proper score: Brier. Secondary: accuracy, CAFR, SRF, RR, CTG, AURC/risk-coverage, invalid-output rate and action-threshold flip rate. Retained language capability is a noncompensable co-interpretation endpoint.

## 5.5 Data and rights

No dataset is admitted merely because a model card is public. Exact source content, license, redistribution, evaluation permission, contamination risk and privacy posture must be frozen. Restricted clinical records are outside the current program. Synthetic or public benchmark transformations do not become clinically valid labels by construction.

## 5.6 Statistical design

Use paired item-level contrasts, cluster-preserving resampling for shared source cases, explicit multiplicity families, frozen tuning budgets and confirmatory quarantine. Numerical meaningful-effect, equivalence and noninferiority margins remain open until justified before confirmatory access.
