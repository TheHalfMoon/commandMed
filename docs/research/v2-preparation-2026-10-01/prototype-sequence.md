Prefer the smallest available qualified Qwen-family base before any 27B work. Kev-0.8B/base revisions are in the manifest as feasibility references; a small scale success cannot be extrapolated to the 27B flagship. A Qwen-Image-2.1 visual pilot can still exceed available resources despite a small backbone: its DiT, VAE, original reference encoder, optimizer/activation memory and evaluation all count. No zero-cost hardware is currently bound; P2–P6 are blocked rather than presumed feasible on a free notebook.

P1 may later be implemented only under an analyzed bounded spec; this packet creates no fixture implementation. P4 must freeze which hidden layer/tokens, masks/positions, sequence length and conditional/unconditional paths feed the 4096-wide DiT input. Start with a linear map; add resampling or cross-attention only when a demonstrated interface/representation deficit requires it. An alignment loss alone cannot establish generation validity.

Every empirical step must use an experiment record with exact code/model/data identities, environment, seeds, primary endpoints, baseline budgets, safety/kill gates, raw outputs, analysis identity and deviations. Development results cannot be relabelled confirmatory. Scale decisions use evidence, not an attractive architecture diagram. A failed head, bridge, encoder removal, budget or rights gate is a retained outcome.
